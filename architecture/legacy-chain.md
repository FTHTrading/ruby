# Legacy Chain

**Owner:** [FTHTrading/Legacy](https://github.com/FTHTrading/Legacy) — registry and Layer 0 coordination

## Role

Legacy Chain (private registry + planned Layer 0 Rust coordination) anchors vault audit events and cross-chain proof routing. For gem RWA it provides:

- Immutable audit trail for manifest publish, VC issue, and release events
- Namespace-scoped identity (`.legacy` estates)
- Future x402 and cross-chain snapshot hooks documented in Layer 0 plans

## Ruby scope

Ruby documents chain anchoring in architecture materials only. Validators and node operations are described in Legacy operator runbooks.
