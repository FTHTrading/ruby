# x402 Metered Access

**Owner:** [FTHTrading/Legacy](https://github.com/FTHTrading/Legacy) + x402 facilitator ecosystem

## Role

HTTP 402 enables machine-payable access to vault exports, compliance reports, and agent-driven workflows without sharing long-lived API keys.

## Modes (Legacy)

| Mode | Description |
|------|-------------|
| `LOCAL_ADAPTER` | Development — no real payment |
| `X402_READY` | Accepts payment proof headers |
| `PRODUCTION_REQUIRES_GATEWAY` | Requires configured gateway |

## Example metered services

| Service | Indicative price |
|---------|------------------|
| Executor packet export | 0.50 USDF |
| Audit log export | 0.25 USDF |
| Compliance report | 1.00 USDF |
| Metered API call | 0.01 USDF |
