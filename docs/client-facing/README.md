## Valuation and disclosure policy

- Package economics are described as a **target package value subject to independent appraisal** — not as asserted net asset value (NAV) in these materials.
- Do not distribute unredacted laboratory reports, custody receipts, or personal identifiers via this repo; provenance lives in Legacy Vault (encrypted storage + private anchoring).

1. Customize party names, jurisdictions, and economics with qualified counsel before any investor communication.
2. Align live product claims with deployed infrastructure (Legacy Vault Protocol, troptionsmint.com, x402 ecosystem capabilities).
