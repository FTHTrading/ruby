# Whitepaper Excerpt — Gem RWA

*Condensed from `docs/WHITEPAPER_RWA_GEMS.md`.*

## Abstract

Institutional tokenization of paired gem assets using Legacy Vault custody, BBS+ credentials, and troptionsmint Token-2022 distribution. Valuation is appraisal-gated.

## Security model

Encrypted storage, DID/VC identity, selective disclosure, isolated mint authority.

## Roadmap bricks

1. Client materials and portal (current)
2. Live VC + intake APIs
3. Branded PDFs and Vercel deploy
4. Mainnet mint with appraisal refs
